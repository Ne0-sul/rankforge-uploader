RankForge Uploader

A private publishing tool for my own YouTube channels.

What it is

RankForge Uploader is the publishing component of a self-hosted video production pipeline written in Python. The pipeline generates short-form informational videos locally — imagery, text-to-speech narration, captions and ffmpeg rendering — and the uploader publishes the finished file to a YouTube channel owned by the operator of the tool.

Who uses it

One person: the developer and owner of the channels it publishes to. The tool is not distributed, not offered as a service, and has no registration, no accounts and no public interface. It runs on a local machine and is operated from a local web interface that is not reachable from the internet.

How it uses YouTube API Services

The tool uses YouTube API Services. It authenticates with the owner's own Google Account via OAuth 2.0 and calls a small set of YouTube Data API v3 endpoints:

  • videos.insert — upload the rendered video file together with its title, description, tags, category and privacy status.
  • thumbnails.set — attach the thumbnail generated by the pipeline.
  • videos.list — read back the processing status of the tool's own uploads to confirm that publishing succeeded.

It writes only to channels owned by the authenticated account. It does not read, collect or store data belonging to any other user, it displays no advertising, and it is not monetised.
