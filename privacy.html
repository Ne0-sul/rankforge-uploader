2. Scope

This policy covers RankForge Uploader ("the application"), a private, locally installed tool used by its developer to publish videos to YouTube channels that he owns. The application is not distributed to other people and has no users other than its developer. It has no registration, no accounts and no public interface, and this website is informational only — it does not process visitor data beyond the standard server logs kept by the hosting provider (GitHub Pages).

3. Use of YouTube API Services

The application uses YouTube API Services. By using it, its operator is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to the application can be reviewed and revoked at any time via the Google security settings page.

4. What data the application accesses

The application authenticates with the developer's own Google Account through OAuth 2.0 and accesses only that account. Specifically it:

  • uploads video files and their metadata (title, description, tags, category, privacy status) to channels owned by that account (videos.insert);
  • sets thumbnails on those uploads (thumbnails.set);
  • reads back the processing status and ID of those same uploads (videos.list).

It does not access data belonging to any other YouTube user or channel, does not read comments, subscribers or audience data, and does not use YouTube Analytics.

5. What is stored, and where

All data stays on the developer's local machine. Nothing is transmitted to any third party other than Google, and nothing is stored on a server operated by the developer. Stored locally are:

  • the OAuth 2.0 refresh and access token for the developer's own Google Account, kept in a local credentials file with filesystem-level access restrictions;
  • the video ID, upload timestamp and processing status of each of the application's own uploads, kept in a local log so the pipeline can detect failed uploads.

No other YouTube API data is stored. Authorised YouTube API data other than the items listed above is not retained; where it is used at runtime it is held in memory only and discarded when the process ends, and in no case longer than 30 days.

6. Sharing

No data is sold, shared, transferred or otherwise disclosed to any third party. There is no advertising, no analytics, no tracking and no profiling.

7. Deletion and revocation

Stored tokens and logs are deleted by removing the local credentials and log files. API access can be revoked at any time at https://myaccount.google.com/permissions; revoking access immediately ends the application's ability to reach the account.

8. Security

The application runs on a single machine under the developer's control. Credentials are stored outside version control and are not copied to any other system. All communication with Google APIs uses HTTPS.

9. Changes

If this policy changes, the updated version is published on this page with a new date.
